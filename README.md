In order to make the program successfully run, you will need to paste the following command into bash:
./mvnw clean spring-boot:run
Then paste the following URL into your browser:
http://localhost:8080/budget
Once it runs, you can enter in your income first, then add expenses with a description, amount, and category. 
Each category displays the target amount to spend, and as you add expenses, your spent amount will increase which you can directly compare to your target amount. 
All the information you put in will be saved, even if you refresh the page.
